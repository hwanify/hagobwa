# 하고봐 릴스 기획

## 콘셉트
- **주인공: 도파민 김씨.** 30대 초반, 늘어난 회색 트레이닝복, 까치집 머리, 무표정. 대놓고 AI인 게 오히려 웃음 포인트.
- **톤:** 병맛 + 공감. 대사는 거의 없고 자막과 표정으로 웃긴다.
- **사운드 로고:** 매 편에 하고봐 구령 "하나! 둘!"이 꼭 나온다. 앱 구령(타입캐스트)과 같은 목소리.
- **엔딩 카드 1.5초:** 빨간 배경 + 하고봐 아이콘 + "운동한 만큼만 앱이 열려요" + "앱스토어에서 하고봐"

## 공통 규칙
- 세로 9:16, 15~25초, 자막은 항상
- 첫 1초 안에 질문형 큰 자막 (스크롤 멈추게)
- 앱 화면은 아이폰 화면 녹화로 실제 화면 사용
- 인스타·유튜브 로고는 크게 보이지 않게(흐림/말로만 "인스타")
- 각 플랫폼에서 **AI 생성 콘텐츠 표시** 켜기
- 개인 계정이 아니라 **하고봐 브랜드 계정**으로 올리기

## 2~6편 한 줄 요약
2. **비상 5분의 배신:** 아껴둔 비상 5분을 쓰자 행복 → 5분 뒤 잠김 + 버튼도 사라짐 → 절규
3. **환율 계산:** "쇼츠 2시간 보려면 푸시업 몇 개?" 계산기 두드림 → 120개 → 기절 (정보형, 저장 잘 됨)
4. **꼼수 실패:** 고양이를 카메라 앞에 세움 → 안 셈 → 결국 본인이 함
5. **구령 중독:** 엘리베이터 층수, 전자레인지 소리가 다 "하나! 둘!"로 들림 (사운드 로고 각인)
6. **1주일 비포/애프터:** 스크린타임 화면 첫날 vs 7일째 + 김씨 팔근육 약간

## 제작 방법 (폰으로 가능)
1. **김씨 캐릭터:** Higgsfield로 캐릭터 시트 1장 → 같은 얼굴로 장면별 3~5초 영상 생성
2. **앱 화면:** 아이폰 화면 녹화 (잠금 화면, 운동 카운트, 충전)
3. **목소리:** 타입캐스트 같은 목소리 (구령 그대로 재사용)
4. **편집:** CapCut (자막, 효과음, 엔딩 카드 템플릿 저장해 두고 재사용)

## 올리는 계획
- 주 3회 (월·수·금 밤 10~11시), 릴스·쇼츠·틱톡 같은 파일
- 승인 전: 1편·5편을 "곧 출시" 티저로 먼저
- 처음 2주에 6편 → 3초 유지율, 끝까지 본 비율, 저장·공유 비교 → 잘 된 콘셉트로 2탄 (예: 환율 계산 넷플릭스 편)
